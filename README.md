# 🔬 Laboratorio di Bioimmagini
### 2026/2027 Course Project – Politecnico di Milano

Welcome to the official repository for the **Laboratorio di Bioimmagini** project, taught by **Prof. Enrico Gianluca Caiani** (Department of Electronics, Information and Bioengineering - DEIB) and the [D-HYGEA Lab](https://d-hygealab.deib.polimi.it/). 

This repository hosts all the exercise materials and code required to develop your final project.

## 🚀 Getting Started

- **Notebooks:** All exercise materials are located in the `notebooks/` directory, subdivided by lab session.
- **Data & Licenses:** Datasets and their respective usage licenses are not public and will be provided separately to students.
- **Environment:** We highly recommend running the notebooks in **[Google Colab](https://colab.research.google.com/)**. It requires zero local setup and provides free GPU access, which is highly recommended for handling the full scope of the project.
